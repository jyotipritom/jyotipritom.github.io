# Dr. Pritom Jyoti Bora — Data Science & Applied AI Portfolio

A responsive, fast, accessible GitHub Pages portfolio for an experienced Data Scientist / AI/ML Researcher / Applied AI Engineer.

**What is included**

- A recruiter-focused landing page, projects and case studies, skills, experience, research publications, contact section and PDF CV.
- Seven editable project overviews, including physics-guided neural networks, Gaussian process methods, live signal analytics, image segmentation, anomaly detection, stock forecasting and multivariable optimisation.
- Project category filters, case-study pop-up panels, mobile navigation, and a working light/dark theme.
- No frameworks, package installations, subscriptions or build tools needed. Just HTML, CSS and JavaScript.
- Careful labelling of project research vs. future uploads. No made-up model performance or live demo links.

## Quick start

1. Open `index.html` in a browser to preview.
2. Edit **`content.js`** to set `githubUsername`, your optional LinkedIn URL, and project details.
3. Create a GitHub repository named **`YOUR-USERNAME.github.io`** (replace with your real GitHub handle).
4. Upload every file in this folder into the **root of that repository**.
5. GitHub repository → **Settings** → **Pages** → under **Build and deployment**, set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** → **Save**.
6. Your site will publish at `https://YOUR-USERNAME.github.io/` after deployment finishes.
7. Add the published URL to the header of your CV.

For a fully illustrated sequence of instructions, see **`SETUP_GUIDE.md`**.

## Easy updates

- **Text/links/projects/skills:** edit `content.js`.
- **Colours/layout:** edit `styles.css`.
- **HTML sections:** edit `index.html`.
- **CV:** replace `assets/Pritom_Jyoti_Bora_Data_Science_CV.pdf` with the latest public-facing version.
- **GitHub link:** add only your username (not a full URL) in `content.js`.
- **Project source links:** add a URL only when you have published the corresponding GitHub repository.

## Publication / research integrity checklist

- Verify whether research results can be released publicly, especially collaboration data and unpublished manuscripts.
- Do not describe an early-stage project as deployed, benchmarked or production-ready until evidence is available.
- Replace the portfolio-draft text for White Hello forecasting and the water-pump anomaly project with verified results and methodology.
- Replace any illustration with *real* plots only if they are authorised to publish; label datasets, evaluation splits and uncertainty clearly.
- Keep raw experimental and partner data private unless sharing is allowed.
